📢 Duyuru yayınla

📧 Gmail HTTPS E-posta Servisi

Minegram doğrulama kodlarını kendi sistemi üretir ve doğrular. E-posta gönderimi Gmail API üzerinden HTTPS ile yapılır. SMTP, 587/465 portu ve domain doğrulaması kullanılmaz.

🔐 Doğrulama Ayarları

Servis durumu

Kontrol ediliyor...

Gmail Client ID, Client Secret ve Refresh Token admin.html içinde tutulmaz. Bunlar yalnızca Render Environment Variables üzerinden sunucuda kullanılır.

📱 Uluslararası Telefon / SMS OTP

Telefon doğrulama kodları SMS üzerinden gönderilir. Uluslararası numaralarda ülke kodunu + ile birlikte kullan: ör. +905551112233.

🔐 SMS OTP Servis Durumu

Kontrol ediliyor...

Twilio hesap bilgileri admin.html içinde tutulmaz. SID, Auth Token ve Verify Service SID yalnızca Render Environment Variables üzerinden sunucuda kullanılır.
